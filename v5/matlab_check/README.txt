MATLAB check of the TCLUST-REG runs (FSDA) for the EESP/ESF paper.
1. In MATLAB Online: Home > Add-Ons > search "FSDA" > install "FSDA - Flexible Statistics Data Analysis Toolbox".
2. Upload and unzip this folder in MATLAB Drive, cd into it.
3. Run, one call at a time (each < 15 min):
     eesp_matlab_check(1,20); eesp_matlab_check(21,40); eesp_matlab_check(41,60); eesp_matlab_check(61,80)
4. Also run:  ver  (and send the output: MATLAB and FSDA versions)
5. Download the four results_*.csv files.
